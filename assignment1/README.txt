In this folder, there are two ipynb files with first one 1-4 means for task 1-4 and task5 mean for task 5. There are also clear titles and annotations to show what each cell is and belongs to. Here are some tips to run the code.

The first cell clearly include all required libraries for the code. These should be installed ahead of running, including PyTorch (for deep learning framework and models), Torchvision (for datasets, pre-trained models, and transformations), Matplotlib (for plotting and visualizing results), Pandas (for data manipulation), NumPy (for numerical operations), PIL (for image processing), Tqdm (for progress bars during training).

The second cell is to load dataset, so make sure to change the path to your dataset folder.
